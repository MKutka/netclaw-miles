# Device Inventory (Meraki-Only)

NetClaw-Miles is a **Meraki-focused** assistant. Device inventory is not defined in a testbed file.

- **Meraki:** Devices, networks, and org hierarchy come from **Meraki Dashboard** (and Meraki MCP). Configure `MERAKI_API_KEY` and use Meraki MCP to list organizations, networks, and devices.
- **Catalyst Center:** If you use Catalyst Center, device inventory is managed there; integrate via the Catalyst Center MCP/skills.

There is no pyATS testbed in this project.
